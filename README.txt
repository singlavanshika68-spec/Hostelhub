HOSTELHUB - BEGINNER FRIENDLY HOSTEL PORTAL (NO JAVASCRIPT VERSION)

How to run:
1. Extract this ZIP file.
2. Open index.html in a browser (Chrome recommended).
3. Enter any registration number and password, then click Login.
4. Use the dashboard to open booking, profile, or student chat.

Project files:
- index.html       Login screen
- dashboard.html   Dashboard and quick links
- booking.html     Hostel booking request form
- profile.html     Sample student profile
- chat.html        Static resident chat preview
- style.css        Styling and responsive layout
- hostel.svg, room.svg, avatar.svg, pattern.svg   SVG illustrations and background pattern

Important demo notes:
- This project uses only HTML and CSS. No JavaScript.
- No backend, no real authentication, and no data is saved.
- Login works with any non-empty details (form action + required).
- Logout is a simple link back to the login page.
- Booking success message is shown with the CSS :target selector.
- Chat message bar is only for display; sending is not functional.
- BH7 and the names/rooms/contact details are fictional sample data only.

For viva:
- HTML makes the page structure, forms, links and validation (required).
- CSS styles the pages, uses images and a repeating SVG background pattern, and shows the booking message using :target.
